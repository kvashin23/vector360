# Вектор 360 — прототип посадочных страниц

Прототип посадочных страниц агентства недвижимости «Вектор 360» для объектов «Карлуу» (Горный Алтай) и «Резиденция. Концепт» (Мариуполь).

- `index.html` — главная страница с «Карлуу». Разметка уже в HTML, картинки и видео загружаются из отдельных файлов. Страницу можно открыть из папки репозитория без сервера.
- `karluu/index.html` и `mariupol/index.html` — страницы объектов по адресам `/karluu` и `/mariupol`. Старые ссылки с `#/` на главную перенаправляются на новые адреса.
- `prototype-src/template.html` — общий шаблон и стили. `prototype-src/render-page.js` — разметка секций и данные объектов.
- `prototype-src/assets/` — картинки (`.jpg`) и видео (`.mp4`). Имя файла без расширения становится ключом в `IMG` или `VID`.
- `prototype-src/build.sh` — собирает все три страницы из шаблона и ассетов. Для публикации нужно раздавать корень репозитория со всеми файлами.

Пересборка после правок (нужен Node.js):

```bash
bash prototype-src/build.sh
```

Визуализации — материалы застройщиков, используются по агентскому договору.

`main` — боевая ветка, `test` — ветка для проверки правок перед переносом в `main`.

## Заявки

Формы на главной, на страницах объектов и в разделе `design/` используют общий обработчик `lead.js`. Он отправляет заявки в [Приёмную Feedback](https://feedback.nuts-agency.ru/clients/4/) на форму `main`. Боевой и тестовый домены зарегистрированы отдельно. Получатель писем — info@vector-360.ru. Цели отправки в Метрике срабатывают после подтверждения приёма заявки сервисом.

Копия каждого письма уходит в amoCRM (infovector360ru.amocrm.ru) на адрес автообработки писем `33367258.324243@parser.amocrm.ru` — он второй получатель в карточке клиента в Приёмной. amoCRM создаёт сделку на этапе «Получена заявка» воронки «Воронка» (не в «Неразобранном»): message → название сделки, project → «Адрес объекта», страница → «referrer», name → имя контакта, phone → «Мобильный телефон», email → «Личный email». Триггер «Salesbot #1» на этапе «Получена заявка» (условие: источник — автообработка писем) распределяет сделки по очереди между Татьяной Дробашевской, Майей Жуковой и Сергеем Жуковым (группа «Менеджеры») и меняет ответственного у сделки и основного контакта. Сотрудники видят только свои сделки и контакты (права «Если ответственный»), Елена — администратор. Если поменять подписи полей в письме (name:, phone:, …) или пересоздать источник в amoCRM, разбор сломается — источник надо настроить заново и обновить адрес в Приёмной.

## Стратегия

`Стратегия продвижения агентства недвижимости.md` — стратегия продвижения. Её показывает страница `strategy/index.html` (на Vercel — `/strategy/`): она подгружает md и рендерит его в браузере. Чтобы обновить ссылку, достаточно поправить md и запушить. PDF можно сохранить кнопкой «Сохранить в PDF» на странице.

## Логотип

`brand/` — логотип «Вектор 360» в двух вариантах (classic и modern), в полной и компактной версии, для светлого и тёмного фона. Буквы в кривых. Превью — `brand/index.html` (на Vercel — `/brand/`). В прототипе компактный логотип встроен в `template.html` как `<symbol>`: цвет слова задаётся через `color`, цвет «360» — через `--logo-gold`.

## Дизайн

`design/` — дизайн посадочных страниц (прототип в `index.html` не меняется):
- `design/karluu/` — «Карлуу» в стиле Алтая (на Vercel — `/design/karluu/`);
- `design/mariupol/` — «Резиденция. Концепт» в морском стиле (`/design/mariupol/`);
- `design/assets/` — картинки и видео для обеих страниц.

Страницы — обычный HTML без сборки, логотип встроен как `<symbol>`.
