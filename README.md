# Вектор 360 — прототип посадочных страниц

Прототип посадочных страниц агентства недвижимости «Вектор 360» для объектов «Карлуу» (Горный Алтай) и «Резиденция. Концепт» (Мариуполь).

- `index.html` — готовый прототип в одном файле: картинки и видео встроены, открывается в браузере без сервера. Переключение объектов — `#/karluu` и `#/mariupol`.
- `prototype-src/template.html` — шаблон страницы: разметка, стили и данные объектов.
- `prototype-src/assets/` — картинки (`.jpg`) и видео (`.mp4`). Имя файла без расширения становится ключом в `IMG` или `VID`.
- `prototype-src/build.sh` — собирает `index.html` из шаблона и ассетов.

Пересборка после правок:

```bash
bash prototype-src/build.sh
```

Визуализации — материалы застройщиков, используются по агентскому договору.

## Стратегия

`Стратегия продвижения агентства недвижимости.md` — стратегия продвижения. Её показывает страница `strategy/index.html` (на Vercel — `/strategy/`): она подгружает md и рендерит его в браузере. Чтобы обновить ссылку, достаточно поправить md и запушить. PDF можно сохранить кнопкой «Сохранить в PDF» на странице.

## Логотип

`brand/` — логотип «Вектор 360» в двух вариантах (classic и modern), в полной и компактной версии, для светлого и тёмного фона. Буквы в кривых. Превью — `brand/index.html` (на Vercel — `/brand/`). В прототипе компактный логотип встроен в `template.html` как `<symbol>`: цвет слова задаётся через `color`, цвет «360» — через `--logo-gold`.

## Дизайн

`design/` — дизайн посадочных страниц (прототип в `index.html` не меняется):
- `design/karluu/` — «Карлуу» в стиле Алтая (на Vercel — `/design/karluu/`);
- `design/mariupol/` — «Резиденция. Концепт» в морском стиле (`/design/mariupol/`);
- `design/assets/` — картинки и видео для обеих страниц.

Страницы — обычный HTML без сборки, логотип встроен как `<symbol>`.
